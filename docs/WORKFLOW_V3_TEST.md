# 可折叠工作流 v3 测试指南

## 📋 概述

全新的可折叠工作流界面 (v3) 已经成功集成到应用中。新界面采用 Accordion 折叠面板模式,解决了之前的"3 个页面跳转"问题。

## 🎯 核心改进

### 1. 可折叠步骤界面
- ✅ 所有步骤同时可见 (不是页面替换)
- ✅ 完成的步骤自动折叠
- ✅ 用户可以随时回到之前的步骤修改
- ✅ 保留上下文和操作历史

### 2. 重新设计的组件
- ✅ **UploadStep**: 专业的拖拽上传界面,使用 Lucide 图标替代 emoji
- ✅ **ProcessingStep**: 圆形进度指示器 + 任务列表
- ✅ **ResultsStep**: 结果导航 + 原图对比 + 导出功能

### 3. 统一设计系统
- ✅ Claude 极简设计系统
- ✅ 专业的配色方案 (#D4A27F 强调色)
- ✅ 流畅的动画效果 (Framer Motion)

## ✅ 测试步骤

### 1. 上传步骤测试
- [ ] 访问首页,看到"上传文件"步骤默认展开
- [ ] 尝试拖拽图片到上传区域
- [ ] 尝试点击上传区域选择文件
- [ ] 验证文件限制:
  - [ ] 支持 JPG, PNG, WebP
  - [ ] 最大 7MB
  - [ ] 最多 10 个文件
- [ ] 查看文件缩略图和文件信息
- [ ] 测试删除文件功能

### 2. OCR 处理步骤测试
- [ ] 上传文件后,看到"开始识别"按钮
- [ ] 点击"开始识别",查看步骤是否自动折叠并展开"OCR 识别"步骤
- [ ] 查看圆形进度指示器显示百分比
- [ ] 查看任务列表显示每个文件的处理状态
- [ ] 验证进度条动画流畅

### 3. 结果步骤测试
- [ ] OCR 完成后,查看"识别结果"步骤是否自动展开
- [ ] 测试多结果导航 (上一张/下一张)
- [ ] 测试"显示原图"功能
- [ ] 查看原图和表格的并排对比
- [ ] 测试表格预览
- [ ] 测试导出按钮 (目前是 mock)

### 4. 可折叠交互测试
- [ ] 点击已折叠的步骤标题,验证是否展开
- [ ] 点击已展开的步骤标题,验证是否折叠
- [ ] 验证可以在任何时候回到之前的步骤
- [ ] 修改已上传的文件,验证状态是否正确更新

### 5. 响应式设计测试
- [ ] 在桌面端 (≥1024px) 查看,验证双列布局
- [ ] 在平板端 (768px-1023px) 查看
- [ ] 在移动端 (<768px) 查看,验证单列布局
