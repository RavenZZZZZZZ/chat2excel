# 阿里云 DNS 配置指南 - yiruo.chat

## 步骤 1：登录阿里云 DNS 控制台

1. 访问：https://dns.console.aliyun.com
2. 在域名列表中找到 `yiruo.chat`
3. 点击"解析"按钮进入解析设置页面

## 步骤 2：添加 DNS 记录

### 记录 1：根域名 A 记录

点击"添加记录"，填写以下信息：

```
记录类型：A
主机记录：@
记录值：76.76.21.21
TTL：10 分钟
```

**说明**：
- 主机记录 `@` 表示根域名（yiruo.chat）
- 记录值 `76.76.21.21` 是 Vercel 的负载均衡器 IP
- TTL 选择 10 分钟可以让 DNS 快速生效

### 记录 2：www 子域名 A 记录

再次点击"添加记录"，填写：

```
记录类型：A
主机记录：www
记录值：76.76.21.21
TTL：10 分钟
```

**说明**：
- 主机记录 `www` 表示 www 子域名（www.yiruo.chat）

### 可选：通配符子域名记录

如果需要支持所有子域名（如 api.yiruo.chat, app.yiruo.chat 等）：

```
记录类型：A
主机记录：*
记录值：76.76.21.21
TTL：10 分钟
```

## 步骤 3：保存配置

1. 点击"确认"保存记录
2. 等待 DNS 生效（通常 5-10 分钟，最长 48 小时）

## 步骤 4：验证 DNS 配置

### 方式 1：使用命令行（推荐）

```bash
cd /Users/ravenz/chat2excel
bash scripts/check-dns.sh
```

### 方式 2：手动验证

在终端运行：

```bash
# 检查根域名
dig +short A yiruo.chat @8.8.8.8

# 检查 www 子域名
dig +short A www.yiruo.chat @8.8.8.8
```

**预期结果**：两个命令都应该返回 `76.76.21.21`

### 方式 3：在线工具

访问以下网站验证：
- https://tool.chinaz.com/dns/
- https://dnschecker.org/

输入域名 `yiruo.chat`，查看全球解析情况

## 步骤 5：访问网站

DNS 生效后，访问以下地址：

- https://yiruo.chat
- https://www.yiruo.chat

**注意**：
- Vercel 会自动配置 SSL 证书（Let's Encrypt）
- 证书通常在 5-10 分钟内自动生成
- 如果访问时显示证书错误，等待几分钟再刷新

## 常见问题

### Q1: DNS 多久生效？

**A**：通常 5-10 分钟，最长 48 小时。使用 `@8.8.8.8` 查询可以绕过本地缓存，看到实时结果。

### Q2: 访问显示 404 或其他错误？

**A**：可能的原因：
1. DNS 还未生效 - 运行检查脚本验证
2. Vercel 项目配置问题 - 检查 Vercel Dashboard 的 Domains 设置
3. 浏览器缓存 - 尝试无痕模式或清除缓存

### Q3: SSL 证书警告？

**A**：
1. 等待 5-10 分钟，Vercel 会自动生成证书
2. 确认 DNS 已正确指向 Vercel
3. 在 Vercel Dashboard 检查证书状态

### Q4: 想修改已有记录？

**A**：
1. 在 DNS 解析列表中找到记录
2. 点击"修改"按钮
3. 修改记录值后保存
4. 等待 DNS 重新生效
