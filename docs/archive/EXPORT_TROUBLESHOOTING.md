# 导出 Excel 问题排查指南

## 问题：点击"导出 Excel"按钮无反应

### 快速诊断步骤

当你点击"导出 Excel"按钮后，请按以下步骤排查：

---

## ✅ 第 1 步：检查是否有错误提示

### 1.1 是否看到弹窗提示？
- **看到"导出成功"提示**：但文件未下载 → 进入第 2 步
- **看到错误提示**：记下错误信息，告诉管理员
- **完全没有反应**：进入第 1.2 步

### 1.2 打开浏览器控制台查看错误

**Chrome/Edge:**
1. 按 `F12` 键（或右键 → 检查）
2. 点击 **Console（控制台）** 标签
3. 点击"导出 Excel"按钮
4. 查看是否有红色错误信息

**Firefox:**
1. 按 `F12` 键
2. 点击 **控制台** 标签
3. 点击"导出 Excel"按钮
4. 查看是否有红色错误信息

**Safari:**
1. 按 `Command + Option + C`
2. 查看控制台输出

---

## ✅ 第 2 步：检查浏览器下载设置

### 2.1 查看下载列表
- **Chrome/Edge**: 按 `Ctrl + J` (Windows) 或 `Command + J` (Mac)
- **Firefox**: 按 `Ctrl + J` (Windows) 或 `Command + Y` (Mac)
- **Safari**: 按 `Command + Option + L`

### 2.2 检查是否被浏览器阻止

某些浏览器会阻止自动下载，你需要：

**Chrome/Edge:**
1. 点击地址栏右侧的**阻止下载图标**（如果有）
2. 选择"允许下载"

**或者检查设置：**
1. 设置 → 隐私和安全 → 网站设置
2. 找到"自动下载"或"更多内容设置"
3. 确保当前网站的自动下载已允许

### 2.3 检查弹出窗口拦截器

某些浏览器的弹出窗口拦截器可能会阻止下载：

**Chrome/Edge:**
1. 地址栏右侧 → 网站设置
2. 找到"弹出窗口和重定向"
3. 设置为"允许"

---

## ✅ 第 3 步：尝试其他浏览器

如果当前浏览器仍然无法导出，请尝试：

| 推荐浏览器 | 下载链接 |
|-----------|---------|
| Google Chrome | https://www.google.com/chrome/ |
| Microsoft Edge | https://www.microsoft.com/edge |
| Firefox | https://www.mozilla.org/firefox/ |

---

## ✅ 第 4 步：检查文件是否在下载文件夹

有时候下载已成功，但你没有注意到：

**Windows:**
- 打开 `此电脑 → 下载` 文件夹
- 搜索 `table-export-*.xlsx`

**Mac:**
- 打开 `Finder → 下载`
- 搜索 `table-export-*.xlsx`

**手机/平板:**
- 打开"文件"或"下载管理器"应用
- 查找下载的 Excel 文件

---

## 📋 需要提供给管理员的信息

如果以上步骤都无法解决，请向管理员提供以下信息：

### 必需信息：
1. ✅ **浏览器名称和版本**（如：Chrome 120.0.6099.109）
2. ✅ **操作系统**（如：Windows 11、MacOS Sonoma、iOS 17）
3. ✅ **控制台错误截图**（如果有红色错误）
4. ✅ **具体现象描述**：
   - 完全没有反应？
   - 有弹窗提示但文件未下载？
   - 下载了但无法打开？

### 如何查看浏览器版本：
- **Chrome/Edge**: 设置 → 关于 Chrome/Edge
- **Firefox**: 菜单 → 设置 → 常规 → Firefox 更新
- **Safari**: Safari → 关于 Safari

## 🔧 常见错误及解决方案

### 错误 1: "表格数据为空或格式错误"
**原因：** 表格识别失败或数据未正确加载

**解决方案：**
1. 刷新页面重新上传图片
2. 查看识别结果是否正常显示
3. 如果识别结果为空，说明 OCR 失败

---

### 错误 2: "浏览器阻止了下载"
**原因：** 浏览器的弹出窗口拦截器或自动下载设置阻止了下载

**解决方案：** 参考第 2 步，允许网站的自动下载权限

---

### 错误 3: "浏览器不支持 Blob API"
**原因：** 浏览器版本过旧

**解决方案：** 更新浏览器到最新版本

---

### 错误 4: "导出失败: xxx"
**原因：** 数据处理过程中出现错误

**解决方案：**
1. 截图错误信息
2. 告诉管理员具体错误内容
3. 尝试刷新页面重新导出

---

## 💡 预防措施

### 最佳实践：
1. ✅ 使用最新版本的 Chrome、Edge 或 Firefox
2. ✅ 允许网站的自动下载权限
3. ✅ 定期清理浏览器缓存
4. ✅ 确保网络连接稳定

### 不推荐的浏览器：
- ❌ Internet Explorer（已停止支持）
- ❌ 过旧版本的浏览器（超过 2 年未更新）

---
