# 表格图片识别导出Excel网站 - 技术栈文档

## 1. 项目概述

本项目是一个基于Web的表格图片识别与Excel导出工具。用户上传包含表格的图片，系统自动识别表格结构并提取数据，支持在线编辑后导出为Excel文件。

### 1.1 项目特点

- **AI驱动**: 基于OCR技术实现表格智能识别
- **高效便捷**: 3秒完成识别，支持批量处理
- **用户友好**: 在线编辑，所见即所得
- **跨平台**: 基于Web，支持多终端访问

### 1.2 技术难点

- 表格结构识别（行列、合并单元格）
- 复杂表格的准确提取
- 大图片的快速处理
- 实时编辑的性能优化

#### Doc2X API v2（表格识别 OCR 服务）

**当前项目版本**: v2 API

**服务概述**:
Doc2X 是一个专业的表格图片识别服务，使用 AI 技术将图片中的表格转换为 Markdown 格式。

**核心特性**:
- **异步处理**: 支持大图片的长时间处理
- **Markdown 输出**: 直接返回 Markdown 格式的表格
- **高准确率**: 表格结构识别准确率高
- **简单集成**: RESTful API，易于集成

**API 端点**:
```
上传图片: POST https://v2.doc2x.noedgeai.com/api/v2/async/parse/img/layout
查询状态: GET https://v2.doc2x.noedgeai.com/api/v2/parse/img/layout/status?uid={uid}
```

**项目集成架构**:
```
前端 → 代理服务器 (localhost:3001) → Doc2X API
```

**为什么使用代理服务器**:
1. **CORS 问题解决**: Doc2X API 不支持浏览器跨域请求
2. **API Key 安全**: 避免在前端暴露 API Key
3. **请求处理**: 统一处理文件上传和状态轮询

**代理服务器实现** ([server.ts](server.ts)):

```typescript
// server.ts - Doc2X API 代理服务器
import express from 'express';
import cors from 'cors';
import axios from 'axios';
import multer from 'multer';

const app = express();
const upload = multer(); // 内存存储
const PORT = 3001;

const DOC2X_API_BASE = 'https://v2.doc2x.noedgeai.com';
const DOC2X_API_KEY = process.env.DOC2X_API_KEY;

// 上传文件到 Doc2X
app.post('/api/proxy/parse/pdf', upload.single('file'), async (req, res) => {
  // 重要：直接发送图片二进制数据，不是 FormData！
  const response = await axios.post(
    `${DOC2X_API_BASE}/api/v2/async/parse/img/layout`,
    req.file.buffer, // 直接发送 buffer
    {
      headers: {
        'Authorization': `Bearer ${DOC2X_API_KEY}`,
        'Content-Type': req.file.mimetype // 如 image/jpeg
      },
      timeout: 60000,
      maxBodyLength: 7 * 1024 * 1024
    }
  );
  res.json(response.data);
});

// 查询识别状态
app.get('/api/proxy/parse/status', async (req, res) => {
  const { uid } = req.query;
  const response = await axios.get(
    `${DOC2X_API_BASE}/api/v2/parse/img/layout/status`,
    {
      params: { uid },
      headers: { 'Authorization': `Bearer ${DOC2X_API_KEY}` }
    }
  );
  res.json(response.data);
});
```

**前端适配器** ([Doc2XAdapter.ts](chat2excel-frontend/src/services/ocr/adapters/Doc2XAdapter.ts)):

```typescript
export class Doc2XAdapter {
  async recognize(file: File, onProgress?: (progress: number) => void): Promise<OCRResult> {
    // 1. 上传文件到代理服务器
    const uid = await this.uploadFile(file, onProgress);

    // 2. 轮询识别结果
    const result = await this.pollResult(uid, onProgress);

    // 3. 转换为标准格式
    return this.adaptResult(result, duration);
  }

  private async uploadFile(file: File, onProgress?: (progress: number) => void): Promise<string> {
    const formData = new FormData();
    formData.append('file', file);

    const response = await axios.post(
      `${this.baseURL}/parse/pdf`, // 代理服务器地址
      formData,
      {
        headers: { 'Content-Type': 'multipart/form-data' },
        onUploadProgress: (progressEvent) => {
          // 上传进度 0-30%
          const progress = Math.round((progressEvent.loaded / progressEvent.total) * 25);
          onProgress?.(5 + progress);
        }
      }
    );

    return response.data.data.uid; // 返回任务 ID
  }

  private async pollResult(uid: string, onProgress?: (progress: number) => void) {
    // 轮询最多 60 次，每次间隔 2 秒
    for (let attempt = 0; attempt < 60; attempt++) {
      const response = await axios.get(
        `${this.baseURL}/parse/status?uid=${uid}`
      );

      if (response.data.data.status === 'success') {
        return response.data.data;
      }

      if (response.data.data.status === 'processing') {
        // 处理进度 30-95%
        const apiProgress = response.data.data.progress || 0;
        onProgress?.(30 + Math.round(apiProgress * 0.65));
      }

      await new Promise(resolve => setTimeout(resolve, 2000));
    }
  }

  private adaptResult(doc2xData: any, duration: number): OCRResult {
    // Doc2X v2 返回格式：result.pages[0].md
    const markdown = doc2xData.result.pages[0].md || '';

    return {
      text: markdown, // Markdown 格式的表格
      items: [{ text: markdown, confidence: 1.0 }],
      status: 'completed',
      duration
    };
  }
}
```

**集成挑战与解决方案**:

| 挑战 | 解决方案 |
|------|---------|
| **CORS 错误** | 创建 Express 代理服务器，前端→代理→Doc2X |
| **请求格式错误** | Doc2X v2 需要二进制数据，不是 FormData |
| **数据结构不匹配** | v2 返回 `result.pages[0].md`，不是 `result.blocks` |
| **进度显示** | 使用轮询机制，上传 0-30%，处理 30-95% |
| **超时处理** | 轮询最多 2 分钟（60 次 × 2 秒） |

**使用流程**:
1. 用户上传图片到前端
2. 前端发送 FormData 到代理服务器 (`/api/proxy/parse/pdf`)
3. 代理服务器读取二进制数据，转发到 Doc2X API
4. Doc2X 返回任务 uid
5. 前端轮询代理服务器查询状态 (`/api/proxy/parse/status?uid=xxx`)
6. 代理服务器转发到 Doc2X，获取最新状态
7. 识别完成后，从 `result.pages[0].md` 提取 Markdown
8. 前端跳转到编辑页面，显示表格

```sql
  NEW.updated_at = CURRENT_TIMESTAMP;

END;
```

### 7.4 实时订阅

```typescript
// 使用Supabase实时功能监听数据变化
export const subscribeToRecognition = (
  recordId: string,
  callback: (payload: any) => void
) => {
  const channel = supabase
    .channel(`recognition_${recordId}`)
    .on(
      'postgres_changes',
      {
        event: '*',
        schema: 'public',
        table: 'recognition_records',
        filter: `id=eq.${recordId}`
      },
      callback
    )
    .subscribe()

  return () => supabase.removeChannel(channel)
}

// 使用示例
subscribeToRecognition(recordId, (payload) => {
  console.log('数据变更:', payload)
  if (payload.eventType === 'UPDATE') {
    updateTableData(payload.new.table_data)
  }
})
```

### 12.2 替代方案

**Python方案**:
```
前端: Vue 3
后端: FastAPI + PaddleOCR
优势: OCR准确度高，开源免费
劣势: Python后端部署复杂
```

**纯前端方案**:
```
前端: Vue 3 + Tesseract.js
优势: 无后端，部署简单
劣势: 识别准确度低，性能差
```
