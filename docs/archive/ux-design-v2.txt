## 设计亮点

### 1. 可折叠步骤界面

**优势:**
- ✅ 用户始终知道当前处于哪个步骤
- ✅ 可以随时回到之前的步骤修改
- ✅ 完成的步骤自动折叠,保持界面简洁
- ✅ 每个步骤的状态一目了然 (待处理/进行中/完成/错误)

**交互:**
- 点击步骤标题 → 展开/折叠
- 完成步骤 1 → 自动折叠,展开步骤 2
- 点击 "展开" 按钮 → 查看详情

### 2. 状态图标系统

```
待处理: ⚪ 灰色圆圈
进行中: ⏳ 加载动画
完成:   ✅ 绿色勾
错误:   ❌ 红色叉
```

### 3. 侧边栏导航

**折叠态 (64px):**
- 仅显示工具图标
- 节省屏幕空间
- 悬停显示工具名称

**展开态 (260px):**
- 显示完整工具列表
- 分类导航
- 工具描述

### 4. 响应式设计

**桌面端 (> 1024px):**
- 侧边栏可折叠
- 主工作区最大宽度
- 双列布局 (原图 + 表格)

**平板 (640-1024px):**
- 侧边栏默认折叠
- 单列布局
- 优化的触摸目标

**移动端 (< 640px):**
- 侧边栏变为抽屉式菜单
- 浮动操作按钮
- 全宽表格

### 新版本优势

```
┌──────────────────────────────────────────────┐
│  可折叠工作流 (单页面)                         │
│                                              │
│  ✅ 步骤 1: 上传文件              [▶折叠]     │
│  ✅ 步骤 2: OCR 识别             [▶折叠]     │
│  📊 步骤 3: 结果编辑             [▼展开]     │
│  ┌────────────────────────────────────┐     │

│  │ [编辑] [导出]                       │     │
│  └────────────────────────────────────┘     │
└──────────────────────────────────────────────┘
```

**关键改进:**
1. ✅ 真正的单页应用 - 所有步骤在同一页面
2. ✅ 保留上下文 - 可以随时回到之前的步骤
3. ✅ 更好的状态反馈 - 清晰的进度和状态指示
4. ✅ 更专业的视觉设计 - 使用图标而非 emoji
