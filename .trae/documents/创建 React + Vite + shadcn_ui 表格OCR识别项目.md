## 执行计划

### 步骤 1: 创建项目基础结构
- 使用 `npm create vite@latest` 创建 React + TypeScript 项目
- 初始化 Tailwind CSS
- 初始化 shadcn/ui
- 配置基础开发环境

### 步骤 2: 安装所有依赖包
- 安装核心依赖（React、状态管理、OCR、表格、导出等）
- 安装开发依赖（TypeScript、ESLint、Prettier、测试工具等）
- 安装 shadcn/ui 组件

### 步骤 3: 创建完整的文件夹结构
- 创建所有必需的文件夹（components、views、stores、services、hooks、lib、types 等）
- 为每个文件夹添加说明注释
- 创建核心配置文件

### 步骤 4: 创建基础配置文件
- 更新 Tailwind CSS 配置
- 更新 TypeScript 配置
- 创建环境变量示例文件
- 创建 .gitignore 文件

### 步骤 5: 初始化基础文件
- 创建 App.tsx 和 main.tsx
- 创建路由配置
- 创建基础组件结构
- 创建类型定义文件

### 步骤 6: 配置开发工具
- 配置 ESLint 和 Prettier
- 配置 VS Code 设置
- 配置 shadcn/ui

完成后，你将拥有一个完整的、可立即开发的项目结构。
